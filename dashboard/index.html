How a value is derived. Implied value = TVL × category multiple × momentum × age. The multiple is the median market-cap/TVL of the tokenised protocols in the same category — the protocols that already trade are the comps, and they are never ranked — blended toward the all-market median in log space, so a category with one wild peer borrows the market's figure. Momentum marks a protocol up or down by its seven-day TVL change; age marks it up the longer it has run with no token. Protocols that are a wrapped, staked or bridged product of a token that already trades are excluded, as are versioned releases and exchange house products.
